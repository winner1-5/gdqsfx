# 客服工单趋势分析工具 - README

## 项目概述

本项目针对客服主管日常工单监控需求，基于50条工单数据自动完成趋势分析、异常识别和可视化呈现，帮助主管快速定位需要关注的问题。

## 分析维度

| 维度 | 说明 | 决策价值 |
|-----|------|---------|
| 时间趋势 | 每日工单量变化、各分类日增量 | 预判人力压力，识别突发问题 |
| 类型分布 | 6大分类占比与排名 | 定位高频问题，指导产品改进 |
| 严重程度 | 优先级分布、高优占比 | 评估风险，确保紧急问题优先 |
| 处理效率 | 平均处理时长、超时工单 | 发现流程瓶颈，优化SLA |
| 满意度 | 平均评分、低分工单占比 | 衡量服务质量，定位用户痛点 |
| 解决率 | 未解决工单、积压情况 | 监控积压，防止问题恶化 |
| 渠道分布 | 在线/电话占比与交叉分析 | 优化渠道资源配置 |

## 关键趋势发现

1. **工单量稳步上升**：从6月1日3条增至6月10日6条，6月8日后持续高位
2. **支付问题占比最高（32%）**：且从6月3日起每日均有，6月11日达单日峰值3条
3. **退款退货处理最慢**：平均45.2小时，是支付问题的8.7倍
4. **高优先级占比62%**：远超正常水平（30-40%），资金类问题占主导

## 异常信号

| 异常 | 严重度 | 判断依据 |
|-----|--------|---------|
| **重复扣款系统性故障** | 极高 | 至少5条工单涉及，T046明确"上个月也有过" |
| **退款退货积压5条未解决** | 高 | 全部满意度1分，最长已等120小时（5天） |
| **投诉类满意度全1分** | 高 | 4条投诉无一例外，服务态度/机器人问题严重 |
| **整体满意度仅2.36** | 中 | 54%工单评分≤2分，低于3.0合格线 |
| **物流查询2条未解决** | 中 | 跨部门协调效率低，平均处理24.5h |
